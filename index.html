SecureFlow

Automated DevSecOps pipeline with AI security analysis
Live ↗ Repo ↗

Security scanning usually gets bolted onto CI/CD after the fact, or skipped when it slows a release down — SecureFlow gates it into the pipeline instead, and I've validated it across 150+ test pipeline executions.

Pipeline
GitHub Actions / Jenkins runs Gitleaks, Semgrep, Trivy, and OWASP ZAP on every commit — secret, SAST, container, and runtime scanning — with a policy engine blocking deploys past severity thresholds.
Dashboard
React dashboard streaming live scan results over WebSockets (FastAPI + PostgreSQL), deployed on GCP Cloud Run.
AI layer
A local remediation copilot (Ollama running Qwen2.5 / DeepSeek-Coder) suggests root-cause fixes, backed by an 800+ line deterministic heuristic engine for when the model is offline.

02 / SECURITY LAB

SentryVault

Banking security lab & SOC operations environment
Repo ↗

Most security portfolios show a scanner. This is the perimeter it would be defending: a production-style, segmented multi-VM DMZ built to actually detect and react to an attack, not just describe one.

Perimeter
Segmented DMZ vs. internal network, Caddy reverse proxy, Coraza WAF (OWASP CRS), and Suricata NIDS enforcing zero-trust controls at the edge.
Detection
Wazuh SIEM for real-time log ingestion, file-integrity monitoring, and alert correlation across a dual MySQL/PostgreSQL data layer.
Response
A Python SOAR script auto-quarantines offending IPs via iptables the moment an alert crosses High/Critical severity.
